# ILLIT 个人互动追星学习指南

私人站点： https://illit-little-world.realruian.chatgpt.site

网站沿用已经确认的视觉，提供五关中文讲解、官方图片与资源、实用互动、实践任务、测验、每关笔记和逐关主动确认。成员档案包含中文常用姓名、英文活动名、韩文、生日与官方访谈转述。中文全名的写法已注明来源，不假称全部为公司正式汉字艺名。

## 本地与构建

运行 `npm ci` 安装测试用 jsdom；运行 `npm run build` 生成 `dist/index.html`，再运行 `npm test`。发布产物内嵌字体、图片、样式和脚本，不需要浏览器加载第三方模块。生产页面没有运行时包依赖；也可直接用浏览器打开构建后的HTML。

## 源码

- `index.html`、`styles.css`：已确认首页和第一关的结构及全站视觉。
- `content.js`：第一关、五关固定名称与基础资料。
- `member-details.js`：五位成员的详细中文档案和访谈来源。
- `chapters-23.js`、`chapters-45.js`：后四关中文讲解、工具、实践、测验与来源。
- `curriculum.js`：统一课程数据与轻量选做建议。
- `explore-content.js`：国内平台、追星表达与歌曲小彩蛋，均为自由探索。
- `progression.js`：逐关确认、存储规范化、旧第一关数据迁移。
- `app.js`：前端导航、成员、词卡、工具、小测、笔记、备份与弹窗。
- `assets/`、`assets.json`：官方视觉素材和来源记录。
- `scripts/build.mjs`：构建自包含HTML，同时校验拼接脚本语法。
- `check.spec.mjs`：对状态逻辑与真实构建产物的DOM行为检查。

## 学习记录

选做记录、工具选择、趣味收藏和手记保存在当前浏览器的 localStorage，不上传至站点服务器。延用原存储键并迁移旧第一关的笔记与主动确认记录。各关实践和小问题均为选做，默认收起的小问题不计分；阅读后即可由用户主动点击「该部分已确认」继续。不自动替用户确认，未解锁关卡只能查看简介；直接访问后续关卡的URL也遵守此规则。

各关手记独立，可在「我的手记」回顾和编辑。页脚与手记页提供JSON备份、带替换确认的导入，以及TXT导出。重置本机记录需第二次明确确认。换设备或清理浏览器数据前请先备份；Safari、其他浏览器和离线文件之间不会自动同步。
